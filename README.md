# SY - Shot 📱

Smart screenshots for Android. Tap the icon or the Quick Settings tile, select an area, then Copy, Share, Save, Edit, Pin to screen or Extract text.

**Latest version:** v1.0.15 · **Android:** 8.0 or newer · No ads, no tracking, no internet permission.



## Download
Get the APK from **[Releases](../../releases/latest)**.

## Install
1. Download the APK on your phone.
2. Open it and allow "Install unknown apps" if Android asks.
3. To update, install the newer APK over the old one. Your settings stay.

Tested on a vivo X300 Pro (OriginOS 7, Android 17).
